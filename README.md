# Legacy System Migration to AWS using Terraform and Ansible

## Project Overview

This project demonstrates the migration of a legacy WordPress application from an on-premises environment to Amazon Web Services (AWS). Rather than performing a manual migration, the entire infrastructure and server configuration are automated using Terraform and Ansible.

The project follows Infrastructure as Code (IaC) and Configuration Management best practices to create a repeatable, secure, and documented cloud migration process.

---

## Business Scenario

An organization is migrating its legacy WordPress application from an aging on-premises Ubuntu server to AWS.

As the Cloud Engineer responsible for the migration, the objectives are to:

- Provision cloud infrastructure
- Configure the application server
- Deploy WordPress
- Validate the migration
- Document the implementation

---

## Project Objectives

- Provision AWS infrastructure using Terraform
- Configure Ubuntu using Ansible
- Install Apache, PHP, and MySQL
- Deploy WordPress
- Validate application functionality
- Document the migration process
